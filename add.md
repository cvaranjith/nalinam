Enhance the existing Nalinam Nrithyalaya website without changing, removing, hiding, or rewriting any existing website content, text, sections, images, buttons, or functionality.

The goal is to make the existing website feel more like a premium **South Indian classical Bharatanatyam art institute** while keeping the overall design clean, elegant, modern, and professional.

### Main Design Direction

Create a refined **classical Indian heritage aesthetic** using subtle Kolam-inspired decorative elements.

Do NOT make the website look crowded or overly traditional.

The Kolam elements should feel like elegant architectural decorations around the website rather than large standalone images.

Use:

* Warm ivory / off-white backgrounds
* Deep black or charcoal sections where appropriate
* Subtle muted gold accents
* Very light traditional texture
* Clean modern typography
* Generous whitespace
* Thin decorative borders
* Soft shadows
* Elegant transitions

Avoid excessive gold, heavy patterns, bright colors, or complicated decorations.

# Section Edge Design

Add subtle Kolam-inspired decorative transitions between major website sections.

Do NOT add large Kolam images between every section.

Instead use:

* Small geometric Kolam motifs
* Tiny lotus-inspired details
* Subtle gold dots
* Fine curved patterns

The transition should feel inspired by traditional South Indian architecture and Kolam designs.

Example:

Hero:
Kolam corner

About:
Small geometric ornament

Training:
Kolam corner

Gallery:
Lotus / Kolam detail

Founder:
Traditional border detail

CTA:
Small centered ornamental divider

Keep the decorations asymmetrical and elegant rather than repeating the same design everywhere.

# Scroll Animations

Add smooth premium animations throughout the existing website.

Use:

* Fade-up
* Fade-in
* Gentle scale
* Soft slide
* Slow parallax
* Image reveal
* Text reveal
* Decorative Kolam reveal

Animation duration:
Approximately 0.6–1.2 seconds.

Use smooth easing.

Avoid:

* Fast spinning
* Excessive bouncing
* Flashing
* Large zoom effects
* Distracting transitions

The website should feel calm and graceful, similar to the movement of Bharatanatyam.

---

# Kolam Animation Concept

The Kolam decorations should visually behave as if they are being revealed during the dancer's journey.

For example:

As the user scrolls into a section:

1. The section content fades upward.
2. The Kolam slowly appears.
3. A subtle line-drawing/reveal effect can simulate the Kolam being drawn.
4. The final Kolam remains softly visible.
5. The decoration gently moves with the page.

Do NOT animate the Kolam continuously in a distracting way.

---

# Mobile Responsiveness

This is extremely important.

On mobile:

* Keep Kolam decorations smaller.
* Never allow them to cover text.
* Never allow horizontal scrolling.
* Maintain proper spacing around headings and buttons.
* Reduce decorative opacity if necessary.
* Keep the dancer and primary website content as the visual priority.

All four Kolam assets must still be used on mobile where practical, but their position and size can change responsively.
